Introduction

{{PROJECT_TITLE}} is a small, fast toolkit for building modern web apps. This guide takes you from install to your first deploy in about five minutes.

Installation

Install the package with your favourite package manager:

npm install {{PROJECT_NAME}}
Note

Node.js 18 or newer is required.

Basic usage

Import it and create an app. Everything is typed, so your editor guides you along the way.

import { createApp } from '{{PROJECT_NAME}}'

const app = createApp({ title: 'Hello' })
app.mount('#root')

Configuration

All options are optional. The defaults are tuned for most projects.

OptionTypeDefaultDescription
titlestring''Document title.
theme'light' | 'dark''light'Initial color scheme.
strictbooleantrueWarn on unknown options.
Heads up

Changing strict to false hides typos in your config.
