# Provider logos for the OpenAI-compatible services

The marks in this folder for the services added with the OpenAI-compatible provider (Settings ▸ AI Provider) are
bundled, never fetched at run time. Each is a trademark of its owner, shown only to name that owner's service.
The six marks the Billing page uses (anthropic, claude-code, gemini, antigravity, ollama, llamacpp) are described
in ATTRIBUTION.md.

Rendered from SVG at 256×256 with a transparent background; the app shows them on a white tile.
